# ИИ-ВЕКТОР

Приложение для анализа налоговой статистики малого и среднего бизнеса
по форме 1-МСП. Загружает общероссийские и региональные Excel-книги,
сравнивает периоды и территории, отвечает на вопросы на русском языке
и формирует отчёты Word.

Расчёты выполняются в Python. Каждое использованное значение связано
с исходной книгой, листом и ячейкой. Языковая модель помогает разобрать
вопрос и сформулировать выводы; числовые результаты проверяются по данным.

## Возможности

- Импорт `.xls` и `.xlsx` с проверкой структуры и карантином повреждённых файлов.
- Сравнение показателей по периодам, регионам, группам МСП и ОКВЭД.
- Анализ динамики, рейтингов, отраслевой структуры и региональных отклонений.
- Чаты с сохранением контекста, таблиц, графиков и аналитических проектов.
- Формирование общероссийских и региональных отчётов по шаблону Word.
- Просмотр источников и проверка происхождения значений.

## Установка и запуск

Нужны Python 3.11 или новее и Node.js 20 или новее.
Команды выполняются из корня проекта. Скрипт совместного запуска требует `zsh`;
для других оболочек используйте [раздельный запуск](DEVELOPER_HANDOFF.md#раздельный-запуск).

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
npm ci
cp .env.example .env
./run_mvp.sh
```

Интерфейс: <http://localhost:4173>.
Документация API: <http://127.0.0.1:8000/docs>.
`Ctrl+C` останавливает frontend и backend.

По умолчанию скрипт использует `.venv/bin/python`. Другой интерпретатор
можно выбрать через `AI_VECTOR_PYTHON`.

## Данные

Исходные книги и шаблоны размещаются локально:

```text
rd/
├── 1_msp_db/       # исторические общероссийские и региональные книги
└── AutoMSP/        # контрольные книги, Коды.xlsx и template.docx
```

Пути настраиваются в `.env`. В интерфейсе откройте «Данные», нажмите
«Сканировать каталог», проверьте результаты и выберите «Импортировать готовые».
Приложение сохраняет импортированные факты и рабочее пространство в `var/`.

Excel-файлы, шаблоны, локальная база, ключи и созданные отчёты в репозиторий
не входят. Без исходных данных интерфейс запускается, но анализ и отчёты
требуют загруженных книг. Для просмотра интерфейса с демонстрационными данными:

```bash
npm run dev:demo
```

## Настройка моделей

Базовый режим `LLM_PROVIDER=deterministic` работает без API-ключа.
Поддерживаются Z.AI и OpenAI-совместимый шлюз GNIVC; параметры заданы
в [.env.example](.env.example).

Настройки ключей хранятся только в локальном `.env`. Отправка реальных
значений модели по умолчанию отключена. Режимы доступа к данным,
настройка провайдеров и аналитического агента описаны
в [техническом руководстве](DEVELOPER_HANDOFF.md).

## Проверки

В активированном Python-окружении:

```bash
python -m pytest
npm test -- --exclude 'handoff/**'
npm run build
```

Полный backend-набор требует исходных книг и заполненной базы: часть
проверок использует реальные эталонные значения и импортированный каталог.
Без данных некоторые тесты пропускаются, другие завершаются ошибкой.
Frontend-тесты и сборка выполняются независимо от исходных книг.
